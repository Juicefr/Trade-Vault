# TradeVault 📊

**A personal crypto trading journal built with HTML, CSS, and JavaScript.**

TradeVault helps traders record, organize, and review their trades in one place. It provides a simple dashboard for tracking trading performance without requiring a backend or database.

##  Features

- **Trade Management:** Add, edit, and delete trade records.
- **Profit & Loss Tracking:** Automatically calculates net P/L after trading fees.
- **Dashboard Analytics:** View total trades, win rate, winning trades, net P/L, average win, average loss, profit factor, and maximum drawdown.
- **Trade History:** View recorded trades, including token, chain, side, strategy, notes, entry price, exit price, and net P/L.
- **Search & Filtering:** Find trades and filter by trade direction.
- **CSV Export:** Export your trade history for external analysis.
- **Local Storage:** Keeps trade records saved in your browser between sessions.
- **Interactive UI:** Smooth hover effects, button animations, toast notifications, and automatic scrolling to the Record Trade form.

##  Built With

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

##  Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build tools are required.

## 💾 Data Storage

TradeVault stores trade records locally in the browser using `localStorage`. Your records are not automatically synced between devices or browsers.

**Important:** Clearing the browser's site data may delete locally stored trades. Export your records regularly as a backup.

## 🎯 Project Goal

This project was built to practise front-end web development, JavaScript DOM manipulation, event handling, form validation, data persistence, and basic financial calculations while creating a useful personal trading tool.
